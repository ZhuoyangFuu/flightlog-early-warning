# Before the Failsafe: early warning of drone loss of control from public flight logs

Code for the HotMobile 2027 submission *"Before the Failsafe: Early Warning of Drone Loss of Control from
Public Flight Logs"* (Zhuoyang Fu, Weisong Shi, University of Delaware).

We learn an early-warning signal for loss of control from the flight logs PX4 pilots already upload to
[PX4 Flight Review](https://review.px4.io). Loss-of-control events are weakly labelled from the logs
themselves (failsafe and flight-termination triggers). A channel-as-token encoder is pretrained by masked
reconstruction on the bulk corpus. Light warning heads on top raise an alarm ahead of the failsafe, at a fixed
false-alarm budget. We compare against classical early-warning signals, shallow baselines and a
time-series foundation model (MOMENT).

**Data is not included.** The raw `.ulg` logs are public on PX4 Flight Review, and `build_index.py` +
`download.py` rebuild the corpus from them. Tensor shards, splits, checkpoints, score dumps and result
tables are generated by the scripts below.

## Pipeline

| Stage | Scripts |
|---|---|
| 1. Index and download | `build_index.py` (download manifest), `download.py` (resumable downloader), `run_bulk.sh`, `run_recover.sh`, `trim_raw.py`, `run_trim.sh` |
| 2. Parse and tensorize | `tensorize.py`, `tensorize_loop.py` (`.ulg` → masked 20 Hz shards), `shard_io.py`, `channels.py` (channel vocabulary), `audit_ulog.py`, `check_aliasing.py`, `validate_tensors.py` |
| 3. Weak labels and splits | `labels.py`, `scan_labels.py`, `validate_labels.py`, `build_splits.py` (A/B/C splits), `build_schema_mask.py`, `run_schema_mask.sh` |
| 4. Classical early-warning signals (Tier 0) | `ews_baseline.py`, `ews_sweep.py`, `ews_eval.py`, `ews_split.py`, `ews_channels.py`, `channel_select.py`, `run_ews_scores.sh`, `run_ews_channels.sh` |
| 5. Shallow baselines (Tier 1) | `tier1_baseline.py`, `horizon_tier1.py`, `run_h1.sh` |
| 6. Foundation-model baseline (Tier 1.5) | `tsfm_baseline.py`, `run_tsfm.sh` (separate environment, `requirements-tsfm.txt`) |
| 7. Pretraining | `pretrain_model.py` (channel-as-token encoder), `pretrain_data.py`, `pretrain.py`, `run_pretrain.sh` |
| 8. Warning heads (Tier 2) | `embed_eval.py`, `embed_views.py`, `flight_relative.py`, `probe.py`, `finetune.py`, `eval_common.py`, `run_embed.sh`, `run_embed_views.sh`, `run_flightrel.sh`, `run_probe.sh`, `run_views_probes.sh`, `run_role_probes.sh`, `run_finetune.sh` |
| 9. Evaluation | `horizon.py` (label-band sweep), `frontier.py` (detection–lead frontier), `sequential.py` (alarm rules), `rule_select.py`, `rule_select_report.py`, `run_horizon.sh`, `run_seq_all.sh`, `run_seq_rel.sh` |
| 10. Tables and figures | `paper_tables.py`, `paper_figs.py`, `paper_figs_v2.py`, `HotMobile/alarm_curves.py`, `HotMobile/figsrc/make_figs.py` (paper figures) |
| Operations | `status.sh`, `watchdog.sh`, `run_flightlog_chain.sh`, `run_role_chain.sh`, `build_results_docx.sh`, `fill_role_rows.py` |

## Environment

- Python 3.12. `pip install -r requirements.txt` for everything except the foundation-model baseline, which uses
  its own environment: `pip install -r requirements-tsfm.txt`.
- Pretraining and embedding passes were run on NVIDIA RTX 3090 GPUs; the classical and shallow baselines are CPU-only.

## Running

- Long jobs have launchers with `start` / `status` / `stop` subcommands. They are detached, resumable and
  invoked as `bash run_<stage>.sh start`, then `bash run_<stage>.sh status`.
- **Paths are hard-coded** to the original machine (`/mnt/wsssd/FlightLog/...` for data and outputs,
  `/home/zhuoyang/venvs/...` for the Python environments). Before running elsewhere, edit these constants
  at the top of the scripts and launchers (`grep -rn "/mnt/wsssd\|/home/zhuoyang" .`).
- Scripts import each other by module name, so run them from the repository root.
